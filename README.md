# AudioReaper downloads

**Soundboard, mic EQ and a mic nobody can steal.**
AudioReaper plays sounds into Discord and games with hotkeys, EQs your mic and speakers, and stops other apps switching, turning down or taking over your microphone.

This repo only hosts the Windows download. Get it from **[audioreaper.com](https://audioreaper.com)**, or directly:

**[Download the latest AudioReaper for Windows](https://github.com/teamgravitydev/audioreaper-download/releases/latest/download/AudioReaper-win-x64.zip)**

To play sounds into voice chat you also need the free [VB-Cable](https://vb-audio.com/Cable/) driver.

Test builds aren't code-signed yet. If Windows says "Windows protected your PC", click **More info → Run anyway**.
